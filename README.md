
# Multi-Utility Calculator

A beginner-friendly Python CLI application that performs arithmetic operations, currency conversion, and unit conversions.

## Features

### 1. Arithmetic Operations
- Addition
- Subtraction
- Multiplication
- Division
- Modulus

### 2. Currency Conversion
- INR to USD
- USD to INR

### 3. Unit Conversion
- Kilometres to Miles
- Miles to Kilometres
- Celsius to Fahrenheit
- Fahrenheit to Celsius
- Kilograms to Grams
- Grams to Kilograms

## Technologies Used
- Python 3
- VS Code

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python3 calculator.py
```

## Note
The currency exchange rate is a demonstration value and is not updated in real time.
